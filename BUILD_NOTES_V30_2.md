# V30.2 — Vendor Badge Hierarchy

Public/member badge rules are now consistent across directory cards, category pages, vendor profiles, Wedding Builder results, homepage featured cards, and vendor dashboard:

- Unclaimed: no membership badge
- Free: no membership badge
- Basic: MPW Vendor
- Pro (`professional` internal key): Pro
- Premium: Featured Vendor
- Founding Vendor: Founding Vendor (overrides the normal plan badge)

Also updated membership marketing copy so Basic includes the MPW Vendor badge, Pro includes the Pro badge, and Premium includes the Featured Vendor badge.
