# MPW Editorial Expansion Roadmap — Review Only

Target: build a deep Portland wedding planning library without publishing thin or mass-produced pages.

## Editorial standard for every publishable guide
- Must answer a distinct couple planning need; no keyword-variant clones.
- Substantial enough to finish the reader's task; no arbitrary word-count target.
- MPW-specific editorial voice and Portland/Oregon context where it materially helps.
- Magazine treatment: strong hero, supporting photography, captions/credits, pull quotes, useful modules, mobile polish.
- Descriptive search title and meta description that may differ from the display headline.
- Article structured data, canonical, crawlable internal links, descriptive image alt text.
- Link to the relevant MPW vendor category, useful related guides, Wedding Builder, and relevant vendor profiles.
- Expert contributions may be included only after editorial approval.
- Featured Vendor placement must be relevant and visibly identified; editorial conclusions remain independent.
- Factual claims that can change must be sourced and reviewed before publication.
- Final desktop + mobile preview approval required before production.
