# MPW Editorial Authority — Preview Gate

This branch is review-only.

Nothing from the next editorial/content expansion should be merged to production until Mitch explicitly approves the preview.

## Visual requirements
- Match the existing My Portland Wedding brand, approved logo, forest green, cream, gold and rose-gold palette.
- Feel like a premium wedding magazine, not a generic blog or AI template.
- Use substantial editorial photography with captions/credits.
- Long-form, useful guides rather than thin SEO copy.
- Featured Vendor modules must feel premium and clearly identified without compromising editorial guidance.
- Mobile layouts must preserve the same brand quality.
- Expert vendor contributions require editorial approval before public display.

## Review sequence
1. Build on this branch.
2. Generate Vercel preview.
3. Review desktop and mobile.
4. Revise until approved.
