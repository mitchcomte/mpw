# v34.2 — Complete Wedding Budget Allocation

- Wedding Builder budget now allocates the couple's full budget across all 22 MPW marketplace categories.
- Budget allocation remains personalized by selected priorities, #1 priority and celebration style.
- Budget display is intentionally ordered with pre-wedding and wedding-day needs first.
- Post-wedding categories are displayed last in a distinct "After the wedding" section.
- Every category displays a dollar allocation and visual allocation bar.
- Expanded base allocation model means non-core marketplace categories no longer default to generic fallback percentages.
- Existing Wedding Builder 3.0 matching, full marketplace coverage and v34.1 signature visual experience are retained.
