# V31.7 — Vendor Badge System + Presence Checker

- Replaces vendor dashboard badge downloads with approved five-level MPW hierarchy:
  - Free: Listed Vendor
  - Basic/entry paid: Supported Vendor
  - Professional: Professional Vendor
  - Premium: Premium Vendor
  - Founding: Founding Vendor
- Adds PNG, JPG and WebP downloads for the vendor's eligible badge.
- Adds copy/paste website embed code linking the badge directly to the vendor's public MPW profile.
- Updates visible tier labels to the new badge naming.
- Adds Admin Vendor CRM "Badge & backlink checker".
- Checker crawls up to 12 same-site public pages looking for MPW badge assets, myportlandwedding.com backlinks, and My Portland Wedding mentions.
- Checker also attempts configured Instagram, Facebook, TikTok, Pinterest and YouTube URLs; platforms that block automated checks are explicitly reported as Unverified, never falsely reported as missing.
- Read-only checker: does not alter vendor websites or social accounts.
