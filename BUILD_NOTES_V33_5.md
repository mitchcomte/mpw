# My Portland Wedding v33.5 — Wedding Builder 2.0

## Experience redesign
- Results are now vendor-first: reveal -> roster mode -> compact budget line -> vendor roster.
- Detailed category budget moved behind an expandable “See how we built your budget” control.
- Roster modes renamed Smart Spend, Perfect Match (recommended), and Dream It Up.
- Added a short interactive build/reveal sequence before results.
- Vendor cards now use the vendor's first gallery image when available, with visible vendor credit.
- “Swap” is presented as “See more [category] options”.
- Existing individual and full-roster contact actions remain intact.

## Better personalization
- Expanded vibe selection to 16 options; couples can choose up to 3 with a primary vibe.
- Added a new celebration-personality step with 8 options.
- Expanded “What matters most?” to 20 choices; couples choose up to 5 and designate a #1 priority.
- Added responsive micro-copy/reactions to make the Builder feel more interactive.
- Matching/budget weighting now gives extra influence to the #1 priority and celebration type.
- New vibe aliases preserve compatibility with vendors that selected the original six style tags.

## Validation note
- Source-level/static checks completed.
- Full Next.js production build was not run because this working snapshot does not include node_modules/dependencies.
- Deploy as a preview first and visually test desktop/mobile before promoting to production.
