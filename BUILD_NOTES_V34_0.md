# My Portland Wedding v34.0 — Wedding Builder 3.0

- Wedding Builder now evaluates every paid-vendor marketplace category defined by MPW, not only the original eight roster categories.
- Core wedding team remains focused and budget-aware; additional categories with active paid vendors appear in a personalized “Finishing touches” section.
- Finishing-touch categories are ordered using the couple’s #1 priority, other priorities, celebration style, and match score.
- Premium vendors receive a modest exposure/matching boost among otherwise qualified matches; Founding vendors also receive a small boost. Paid tier never overrides basic compatibility.
- Core vendor results were redesigned into compact editorial cards with much smaller imagery, tighter match reasoning, pricing, badges, and actions.
- Extra marketplace recommendations use an even more compact format to keep the results page scannable.
- Existing Builder analytics, match notifications, lead flow, three roster modes, visible budget visualization, and results auto-scroll are retained.
- Added a subtle approved MPW heart-and-sprig brand watermark and richer interactive selected states.
