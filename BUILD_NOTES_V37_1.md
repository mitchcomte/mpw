# v37.1 — Wedding Builder Powerhouse Preview

Built on v37.0. Adds the next Wedding Builder intelligence layer for preview testing:
- persistent local wedding plan save
- guest-count simulation can be applied back into live matching
- Wedding Gap Finder
- whole-roster Team Chemistry / compatibility indicator
- Planned vs Real committed-spend tracking
- Quote Decoder preview for pasted proposal/package text, with explicit uncertainty rather than invented inclusions
- preserves Budget DNA, Wedding Lab, locked must-have vendors, Smart Spend / Perfect Match / Dream It Up, live rebalancing, vendor matching, contact flows and analytics

No Supabase migration required for this preview. Saved plan and committed-spend data are browser-local in this build so the experience can be tested before committing to an account-level persistence schema.
