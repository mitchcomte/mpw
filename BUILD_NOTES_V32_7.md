# MPW v32.7 — Badge Package Outreach

- Keeps the centralized Admin → Badge & Backlink Center and Scan All Vendors workflow.
- Adds badge-package access tracking when a vendor downloads PNG/JPG/WebP or copies the website embed code.
- Adds an Eligible for Email state: scanned, no badge/backlink/mention detected, no recorded badge package access, and a valid email.
- Adds Select All Eligible plus individual recipient checkboxes.
- Adds Send Badge Package Email with a required recipient-count confirmation.
- Email is personalized to the vendor's correct Listed, Supported, Professional, Premium, or Founding badge and includes PNG/JPG/WebP links, profile backlink instructions, and a direct dashboard link to the badge package/embed code.
- Records successful sends as analytics events so Admin can see Email Sent vs Accessed.
- Never-scanned or Unverified vendors are excluded from automatic outreach to avoid emailing vendors whose public presence could not be confidently checked.
